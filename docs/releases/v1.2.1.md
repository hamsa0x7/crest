**New**

- An Insert key alert: when Insert is pressed alone, the closed notch shows it for a moment, like Caps Lock. It never says on or off, since each program keeps its own overtype state, and shortcuts such as Shift+Insert show nothing. On Windows, off by default: Settings → Display → Status alerts → **Insert key** ([#45](https://github.com/andrealo20/crest/issues/45)).
- The Hardware tool lists USB sticks, SD cards and external disks, after the internal drives ([#42](https://github.com/andrealo20/crest/issues/42)).

**Changed**

- With Glass on and a dark theme, the album cover behind Now Playing no longer turns the glass off: the cover stays over the glass, partly see-through. On a light theme it still turns the glass off, so the light text over the cover keeps its contrast.
- With Glass on, the top of a panel hanging from the screen edge is glass too, instead of a black band in the closed notch's colour ([#49](https://github.com/andrealo20/crest/issues/49)).
- The gear in the tool bar opens Settings like any other tool: a second click no longer goes back to the last tool ([#49](https://github.com/andrealo20/crest/issues/49)).

**Fixes**

- Bluetooth audio no longer breaks up every minute or two on some PCs while the **Bluetooth devices** alert is on. Crest now reads the paired devices from the list Windows keeps of them, instead of keeping a search for devices running ([#48](https://github.com/andrealo20/crest/issues/48)).
- A cloud drive that mounts a letter, such as Google Drive, no longer adds its size to the system drive's row in Hardware ([#42](https://github.com/andrealo20/crest/issues/42)).
- Notices from Windows Security and other apps that register an icon for their notifications now show that icon instead of the first letter ([#43](https://github.com/andrealo20/crest/issues/43)).
- With the song title's Lyrics switch on, a paused song shows its title again instead of the line it stopped on ([#46](https://github.com/andrealo20/crest/issues/46)).

Try every tool in your browser before installing: [crestisland.app](https://crestisland.app/).
